Questions

  • What does akproxy do?

    It runs a small server on your computer. Tools that only speak the OpenAI API point at it and use the Codex, Claude, Gemini, Kimi, Grok, and Devin subscriptions you already pay for. Sign in once in the browser, then paste the address and key into the tool.

  • Where do my requests go?

    Only to the provider you signed in to. akproxy passes along what your tool sends and hands the reply back. It runs on your own machine and keeps your login there. There is no akproxy server in between.

  • Could my account get banned?

    It could. Requests go out on your own account, from your own computer, not a shared pool. But each provider has its own rules about using a subscription outside its official app, so we can't promise it won't happen.

  • Which tools can use it?

    Any tool that lets you set an OpenAI base URL and API key. Home shows both, plus a .env and SDK examples you can copy.

  • Can I see how much quota is left?

    Yes. Each account card shows the plan and how much of this week's quota is left, and warns you when it may run out before the reset.
