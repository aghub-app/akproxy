# 未运行的首页用空状态，不保留分段

状态：已接受

## 背景

已有上游凭据时，首页用「接入」和「测试」展示地址、密钥和命令。服务未运行时，这些内容要么藏起卡片只留一句提示，要么仍渲染命令但禁止复制。分段本身也留在页面上。

产品要求未运行时不展示这些内容，也不展示分段，改为与上游页相同的居中空状态。没有上游凭据时仍先引导添加账号。

## 决定

空状态只由已经存在的「是否有上游凭据」和「服务是否在运行」决定，不新增接口。

有凭据且未运行：内容区只有空状态。图标用与导航栏启动按钮相同的播放图标。标题是「启动服务」。描述只说服务还停着，以及去窗口右上角点一下就会跑起来，不预告启动后会出现哪些内容。指向右上角的箭头是独立的手绘 SVG，放在描述旁边，不进入文字流。空状态上没有第二个启动控件。

没有凭据：无论服务是否在运行，都显示六张提供商卡片。

正在运行且有凭据：显示分段。停止后整页换成空状态，不保留分段选择。

## 备选

- 保留分段，只禁用复制。页面上仍是一堆不能用的命令。
- 空状态里再放一个启动按钮。导航栏已经有唯一的服务控制，两个入口会分叉失败和进行中的状态。
- 把小箭头嵌进描述文字。方向对，但和正文挤在一行，也太规矩。

## 后果

停止或启动失败后，人在首页会看到空状态，而不是接入或测试。启动成功后分段重新出现，并回到默认的「接入」。读取首页失败仍显示错误和重试，不显示成空状态。
