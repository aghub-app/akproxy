# 主窗口固定大小

状态：已接受

## 背景

主窗口目前以 1120×760 打开，并允许缩放到最低 880×640。产品要求保持当前初始尺寸，不再提供调整大小或全屏的窗口操作。

## 决定

在 Wails 主窗口的原生选项中禁用调整大小，并禁用最大化和全屏按钮；macOS 同时禁止窗口进入全屏模式。移除原有最小尺寸约束；窗口始终以 1120×760 打开。保留移动、最小化和关闭操作。

## 备选与后果

把最小和最大尺寸都设为 1120×760 也能限制部分缩放路径，但仍可能保留误导性的原生调整控件。使用 Wails 已有的禁用选项，不引入前端窗口状态。固定尺寸减少了小屏幕与大屏幕上的布局弹性；验收需在真实 macOS 窗口检查边缘拖动和绿色按钮。
