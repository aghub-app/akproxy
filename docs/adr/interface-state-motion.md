# 界面状态动效的边界

- 状态：已采纳

## 背景

窗口以 React、Base UI 和 CSS 实现，Toast、弹窗、标签指示器和开关已有动效。新增机会集中在少量条件渲染和语义状态切换。高频导航及额度数据要求稳定，不能为了装饰而移动。

## 决定

动效由呈现层按语义状态触发，使用 Motion for React 的声明式组件和退出管理；共享进入缓动为 `cubic-bezier(0.23, 1, 0.32, 1)`。只动画透明度与变换，时长不超过 200ms。首页和账号卡片只在状态或身份首次变化时进入；设置条件字段由退出管理短暂保留，但立刻移出可交互范围；更新阶段只淡入非交互内容。减少动态效果时移除位移和缩放，缩短为 100ms 淡入。

## 备选与取舍

- 全局路由转场：覆盖高频操作，容易拖慢导航，不采用。
- 手写关键帧与退出计时器：五处虽短，但条件字段退出及快速反向切换需要统一生命周期；使用 Motion 减少重复状态代码。
- 所有条件内容立即卸载：实现简单，但设置字段无法完成退出；只在两个低频设置字段保留短暂退出状态。

状态判断和定时器只属于渲染层，不进入配置或后端。验证需同时覆盖快速反向操作、后台刷新、键盘焦点和系统减少动态效果偏好。
