# 首页数据与命令

状态：已接受

## 决定

复用 hash 路由，根路径 `/` 直接呈现首页；provider 导航数据在侧边栏和首页共享。Go 继续拥有配置及账号文件，新增只读首页快照，返回凭据是否存在、第一把客户端密钥和现有 Status，不向前端传递上游密钥。

模型列表通过 Go 请求当前运行服务的 `/v1/models`，复用 Status 的实际绑定地址及客户端认证。使用标准 HTTP 客户端，设超时、限制响应大小、禁止重定向与环境代理，保留 TLS 证书校验。错误不携带响应正文或密钥。前端采用现有 TanStack Query 定期刷新；命令文本在前端由地址、密钥、模型生成，采用 POSIX shell 参数转义及 JSON 序列化。

## 备选与边界

前端直接 fetch 更少绑定代码，但桌面源涉及跨域及 TLS 边界；读取 SDK 全局模型注册表不能验证客户端实际获得的列表，因此请求本地 HTTP 接口。未运行时不请求模型，不自动启动。不新增全局持久状态或依赖；模型选择只属于当前首页。

配置和账号读取失败使快照失败；模型错误仅影响模型选择，命令保留占位符。以已有测试工具验证凭据分支、实际地址、HTTP 认证与错误处理，前端构建与交互检查验证命令和导航。
