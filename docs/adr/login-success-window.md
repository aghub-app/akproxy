# 登录成功后先把主窗口带到前面，再刷新账号列表

状态：已接受（2026-09-25）

## 背景

浏览器登录在系统浏览器里完成。成功提示音来自渲染进程的成功 toast，账号列表也是在同一次登录返回之后重新读取。窗口当时通常还在浏览器后面。新增账号卡片会从透明状态进入；页面不可见时这段动画停在起始帧，用户点回窗口时列表看起来没有这条账号。

## 决定

凭据已经写入之后，先取消最小化、显示并聚焦主窗口，再发出登录完成事件。界面收到该事件后重新读取账号列表和额度，登录调用返回后、成功提示音之前再读一次。被取消的读取不得写回查询结果。失败和取消不改变窗口层级。

## 备选

- 只在 toast 之后由界面请求聚焦。列表可能已经在窗口不可见时画完，新卡片仍停在透明状态。
- 成功后不聚焦，只靠用户点回窗口。后台动画停住时，新账号仍然看不见。

## 后果

成功登录会把主窗口放到当前浏览器前面。这只发生在凭据写入之后。重新授权成功走同一条路径。
