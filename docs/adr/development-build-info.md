# 开发版构建信息在编译时确定

状态：已接受

## 背景

关于页现有 `Version()` 只返回构建注入的 `dev` 或正式版本号。已构建的开发版不能仅凭这个字符串辨认来源。运行时查询当前目录的 Git 状态可能与实际二进制不一致；当前 Go 产物也未自动携带 VCS 字段。

## 决定

- 构建任务从 Git 读取提交 hash，写入开发版二进制。关于页通过单个只读绑定获取版本和 hash。
- 仅 `dev` 在版本行展示短 hash；正式版本不展示 hash。缺少 Git 元数据或通过其他命令直接构建时，hash 保持空值，由界面显示不可用，不在应用运行时补查当前仓库。
- 构建时间、工作区状态、完整 hash、提交时间、分支和 Go 版本不占用关于页空间。

## 备选与后果

运行时执行 `git` 会误认安装位置附近的仓库，也会让安装包依赖 Git；不用。另建版本文件需额外生成和清理；沿用现有构建任务注入值。正式发布任务的版本号与更新流程不变。

## 验证

构建开发版并检查其返回的 hash；验证没有 Git 元数据时的显示，以及正式版本不显示 hash。
