# 首页命令用 sugar-high 按 shell 高亮

状态：已接受

## 决定

首页三张 curl 卡片的可见文本用 sugar-high 按 shell 高亮。复制按钮写入的仍是未高亮的纯文本命令。颜色沿用界面已有的前景、说明和成功色，并跟随系统浅色或深色。不使用实验性的 GPU 高亮。

## 备选

- highlight.js 或 Prism。对三张短命令过重。
- 把命令里的 JSON 正文再按 JSON 高亮。正文包在 shell 字符串里，拆开会和复制出去的命令分叉。

## 后果

地址、密钥和模型中的 HTML 字符必须转义后展示。隐藏密钥时，高亮的是遮挡后的命令。高亮失败不应改变可复制的命令。
