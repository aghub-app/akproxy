# 用 gum choose 选择模型

状态：已接受

## 背景

`akproxy model` 要从本机代理的模型列表里选一个，写进 `cli.json` 的 `model.id`。列表可能不止一屏。产品要求选择界面直接用 gum，并保持它自己的样式。

## 决定

- 选择界面调用 `charm.land/gum/v2/choose`，不另画一套列表。
- 颜色、光标和帮助沿用 gum choose 的默认值：光标和选中项前景色 212，标题前景色 99，光标前缀 `> `，高度 10，显示帮助。标题文字保持 gum 的 `Choose:`。
- 已选模型若仍在列表里，光标从它开始。确认后覆盖 `cli.json`。取消、中断或列表为空时不写文件。
- 模型来自配置里的代理地址加 `/v1/models`，用第一把客户端密钥。连不上就失败，不启动代理。专用的命令行密钥还没做。

## 备选

- 自己用 bubbletea 画列表。要重做 gum 已经有的按键、分页和配色。放弃。
- 用 `gum filter`。适合很长的列表，但这一步要的是 gum choose 那种直接点选。放弃。
- 调用本机安装的 `gum` 可执行文件。版本和样式会随用户环境变。放弃。

## 验证

- 列表排序、写入、取消不覆盖，由 `go test ./internal/cli/` 覆盖。选择界面本身走 gum，不在测试里打开终端。
