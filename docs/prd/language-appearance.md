# 语言与外观

## 问题与用户

akproxy 目前只有中文界面，颜色只跟随系统。使用英文系统或希望自行指定界面语言、明暗的用户无法调整。

## 范围与流程

- 设置 → 外观标签提供语言和外观设置。语言可选「跟随系统」「简体中文」「English」；外观可选「跟随系统」「浅色」「深色」。两项默认跟随系统。
- 系统语言为中文时使用简体中文，为英语时使用英语；其他系统语言回退到简体中文。手动选择覆盖系统语言，重新选择跟随系统后恢复跟随。系统语言或外观变化时，跟随系统的项目同步变化。
- 选择立即作用于当前窗口，重启应用后保留。旧版偏好文件缺少这两项时沿用跟随系统。
- 同一标签提供「直播模式」，默认关闭。打开后，各服务商账号卡片标题里的邮箱，以及删除确认里引用的同一邮箱，显示为固定的 `••••@••••`，页面上不再出现原来的地址。不是邮箱的账号名称保持原样。关闭后恢复。改动立即生效，重启后保持。不改账号文件。
- 英文覆盖应用拥有的页面、操作反馈、错误提示、辅助技术标签和自定义原生菜单文案。产品名称、提供商名称、API 标识、配置值和第三方返回的原始错误内容保持原样。
- 日期、数字和时间格式跟随当前界面语言。

## 非目标

第三种翻译语言；翻译上游或操作系统拥有的文案；改变代理服务的接口、配置文件及账号数据。

## 失败与验收

1. 新装或升级后，两项设置默认跟随系统；不支持的系统语言显示简体中文。旧 `app.json` 的其他偏好保持原值。
2. 切换语言后，各页面、提示、应用错误和自定义「关于」菜单使用所选语言；重启后仍使用所选设置。系统语言变化只影响「跟随系统」。
3. 切换外观后窗口立即变成浅色或深色，重启后保持；系统明暗变化只影响「跟随系统」。
4. 两项设置保存失败时提示错误并恢复已保存的选择；代理运行、登录、更新与账号数据不受影响。
5. 直播模式默认关闭。打开后账号卡片和删除确认里的邮箱不可读，关闭或重启后按已保存的选择显示。其他页面不打码。
