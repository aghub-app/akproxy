# 账号额度显示

## 问题与用户

使用 akproxy 管理多个上游账号的人，需要在各账号卡片上看到厂商返回的套餐和额度，判断何时切换账号。读取失败不能影响其他账号，也不能把缺失的数据写成零。

## 范围

- Codex、Claude、Grok、Devin 的已保存账号分别显示套餐名（有数据时）和厂商额度窗口。账号卡片保持每行两张；卡片标题空间不足时可以省略账号邮箱，但须完整显示套餐名。没有账号时保持居中的添加入口。Gemini、Kimi 不显示额度。
- 窗口以进度条显示已用或剩余百分比、重置倒计时或具体时间。接近限额或按当前节奏预计触及限额时提示；用户可以始终显示使用节奏。
- 厂商明确返回时，显示 Claude 的额外费用已用金额、Codex 的积分余额与可用重置次数、Devin 的超额余额，以及 Grok 的按量付费上限或关闭状态。金额、积分和次数保留各自单位；缺字段时不显示对应行。
- 设置 → 用量提供额度总开关、百分比模式、重置时间模式、使用节奏开关，以及额外额度和重置次数的显示开关。总开关关闭时，下面的选项变灰且不能操作，原有选择保留到再次开启。设置即时保存并在重启后保持。
- 总开关默认开启。开启后，应用对有账号的 Codex、Claude、Grok、Devin 在后台读取额度，每 60 秒刷新；页面切换复用已读结果。首次读取期间显示读取状态，后台刷新不清空已有数据。关闭后停止读取和自动刷新、隐藏手动刷新按钮；重新开启后恢复读取。
- 新增或删除账号后刷新该页账号和额度。用量设置尚未加载或加载失败时不发起额度请求；失败时提供重试。手动刷新失败给出可见提示。账号令牌不显示在界面上。

## 厂商窗口

- Codex 按厂商报告的时长显示 5 小时、每周或每月窗口；30 天窗口不标为每周。套餐来自 usage 响应。
- Claude 显示 5 小时、每周，以及有数据时的每周 Opus / Sonnet 窗口。套餐资料读取失败时只省略套餐名。
- Grok 显示周窗口；旧月付响应没有周窗口时只显示可得的套餐和附加额度，不画空进度条。
- Devin 显示每日和每周窗口；厂商隐藏每日额度时不显示每日窗口。没有可用窗口时报告读取失败。

## 失败与边界

- 每个账号独立读取。厂商请求失败或账号缺少可用令牌，只在该账号上显示原因。
- 缺失窗口或附加指标不显示为 0；只有厂商协议明确省略零值的完整响应才按零解释。
- 额度和套餐依赖厂商接口；本功能不汇总多个账号，也不显示 Gemini、Kimi 的估算额度。

## 验收

1. 四个支持的上游按各自可用窗口显示套餐、百分比和重置时间；Gemini、Kimi 没有额度区域。
2. Codex 月窗口、Grok 旧月付响应、Devin 隐藏每日窗口及缺失附加指标，都不产生错误的窗口或假零值。
3. 厂商返回的附加额度和重置次数按原单位显示；设置可分别隐藏。
4. 额度总开关、百分比、重置时间和节奏选项即时生效，重启后保留；关闭总开关后不再请求额度。
5. 首页或设置页停留期间仍定期读取已有账号额度；切换账号页复用已读结果，首次未完成或失败时显示对应状态。
6. 一个账号读取失败不遮盖其他账号；手动刷新失败有反馈；无账号时保留原有空状态；界面不显示令牌。
