# Wails v3 迁移

## 目标与范围

为后续官方自动更新能力迁移到 Wails v3。用户要求先将完整、可构建的迁移独立提交并推送，自动更新另行实现。

## 兼容要求

- 保持本地代理 PRD 中的导航、配置、登录、额度及启动/停止行为。
- 保持应用名称、配置和账号路径以及 macOS bundle identifier，不迁移或重置已有数据。
- 关闭主窗口即退出应用并停止代理，不因额外窗口而留存代理进程。
- 前端依然使用 pnpm、React 和 coss UI。构建与开发统一使用固定版本的 Wails v3 CLI。
- 原有 tag 触发 macOS DMG artifact 工作流随迁移更新；这次不创建 GitHub Release。

## 验收

Go 测试和前端构建通过；macOS `.app` 与 DMG 可生成；真实桌面窗口能加载设置并通过 Go 绑定查询状态；关闭窗口后进程退出。自动更新、签名、公证和多平台发布不属于此次提交。
