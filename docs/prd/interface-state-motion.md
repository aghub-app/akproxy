# 界面状态动效

## 问题与用户

用户添加首个上游或账号、启动服务、展开条件设置，以及查看更新阶段时，内容直接出现或替换，状态关系不够清楚。动效只帮助识别这些低频变化；日常导航和数据阅读仍须迅速、稳定。

## 范围与流程

- 首页在无凭据、已有凭据但服务停止、服务运行三种状态之间切换时，新内容短暂进入。首次读取、读取失败和定期刷新不重复播放。
- 六个服务商页在成功新增账号后，仅新增卡片短暂进入；已保存卡片、额度刷新和页面往返不重复播放。
- 设置的自定义监听地址和自定义更新间隔在出现与隐藏时短暂过渡。隐藏开始即不可操作、不可聚焦，快速反向切换仍能正常使用。
- 更新对话框在发现新版、下载、校验、准备安装、就绪及失败之间切换时，阶段说明短暂淡入。下载进度变化和同一阶段重新打开不重播。操作按钮立即可用。
- 减少动态效果的系统偏好下，保留简短淡入，不产生位置或缩放移动。

## 非目标

不为侧边栏导航、首页分段、额度数字与进度、后台轮询、普通按钮和已有弹窗开关增加动画。不改变服务、登录、设置保存或更新行为。

## 验收

1. 五种场景按上述触发条件各播放一次；相同语义状态的数据刷新不重播。
2. 快速切换两项自定义设置时，没有失效输入仍可聚焦，也没有残留的不可见控件。
3. 所有业务操作在动效开始时即可使用，不等待动效完成；动画不改变复制内容、配置或账号。
4. 减少动态效果偏好下只有短暂淡入。已有 Toast、弹窗与标签指示器行为不受影响。
