# 首页

## 目标与流程

用户打开应用进入 `/`，侧边栏最上方为「首页」。没有上游凭据时，展示 Codex、Grok、Claude、Gemini、Kimi、Devin、Meta 七张图标与名称卡片，点击进入对应页面。

当前存在至少一个上游登录账号或非空上游 API key（含配置文件中的原生 key，以及已经写在配置文件里的 OpenAI 兼容项），且服务正在运行时，用分段在「接入」和「测试」之间切换，默认是「接入」。客户端密钥不计为上游凭据。删除全部上游凭据后恢复卡片，不显示分段。已有上游凭据但服务未运行时，不显示标题、分段和任何接入或测试内容，只显示居中空状态。

## 命令与状态

- 已有上游凭据且服务未运行时，内容区只有空状态：播放图标、标题「启动服务」，以及一句描述，只说服务还停着、去窗口右上角点一下就会跑起来。描述旁边另有一枚手绘箭头指向窗口右上角，箭头不写进文字里。没有第二个启动按钮。没有上游凭据时不使用这个空状态。
- 「接入」在服务运行时展示当前绑定地址、客户端密钥，以及一份 .env：`OPENAI_API_KEY` 和 `OPENAI_BASE_URL`（地址带 `/v1`），没有 `export`。有多把客户端密钥时，可在密钥卡片中选择，默认选第一把；列表变化后若所选密钥已被删除，回退到首项。选择只在当前首页保留。另有一张 SDK 卡片，标题上切换 OpenAI Python、OpenAI Node、AI SDK、LangChain、LangChain.js，示例使用所选密钥。这些都是卡片。固定窗口内，地址卡片比密钥卡片窄，显示密钥时能看完整把生成的客户端密钥。密钥卡片、.env 和 SDK 示例默认一致地显示八个圆点。密钥卡片标题区在「复制」左侧提供「显示密钥/隐藏密钥」按钮，统一切换这三处可见值；选中另一把密钥后重新遮挡。所有复制内容始终包含所选真实密钥。
- 「测试」在服务运行时展示三个 curl 示例：GET `/v1/models`、POST `/v1/chat/completions`、POST `/v1/responses`。复制成功或失败都有反馈。使用首页所选客户端密钥，默认遮挡，可切换显示；复制包含所选真实客户端密钥，绝不包含上游凭据。展示按 shell 语法高亮，复制的仍是纯文本命令。
- 运行时命令和接入信息使用当前绑定地址。监听修改尚未重启时仍使用旧绑定地址。
- 运行时自动读取模型列表，默认选择首项，可手动选择，两个生成示例共用模型。列表变化后失效选择回退到首项。
- 运行中读取失败或没有模型时使用 `<MODEL_ID>` 并提示替换。不自动启动服务。
- 导航栏成功点「启动」后，提示「服务已启动」，并说明可以到首页看接入方式。人已经在首页、或这一页还在展示上游卡片时也提示。停止和重启成功不提示。启动失败只显示失败原因。
- 读取凭据失败显示错误与重试，不误报为零凭据。首页定期刷新，返回首页读取最新状态。

## 验收与范围

验证七张卡片导航、默认入口、登录与 API key 两种分支、清空后回退、已有凭据但未运行时只有空状态且没有分段、运行后分段默认停在「接入」、启动后地址与密钥可复制、多把密钥切换后显示和所有复制内容同步、删除所选密钥后回退到首项、密钥开关位置、三处同步显示与默认八点遮挡、复制仍含真实密钥、模型联动、停止后回到空状态、监听未重启地址，以及命令高亮不改变复制内容。仅请求模型列表，不自动执行生成请求，不保证所有模型同时支持两种生成协议。高亮使用 sugar-high。无凭据迁移。
