# 首页

## 目标与流程

用户打开应用进入 `/`，侧边栏最上方为「首页」。没有上游凭据时，展示 Codex、Grok、Claude、Gemini、Kimi、Devin、自定义 OpenAI 七张图标与名称卡片，点击进入现有页面。

当前存在至少一个上游登录账号或非空上游 API key（含配置文件中的原生 key、Kimi 兼容项及自定义 OpenAI）时，用分段在「接入」和「测试」之间切换，默认是「接入」。客户端密钥不计为上游凭据。删除全部上游凭据后恢复卡片，不显示分段。

## 命令与状态

- 「接入」只在服务运行时展示当前绑定地址、第一把客户端密钥，以及一份 .env：`OPENAI_API_KEY` 和 `OPENAI_BASE_URL`（地址带 `/v1`），没有 `export`。另有一张 SDK 卡片，标题上切换 OpenAI Python、OpenAI Node、AI SDK、LangChain、LangChain.js，示例写入当前地址和第一把密钥。这些都是卡片。密钥默认遮挡，可显示和复制；环境变量和 SDK 示例的复制内容包含真实密钥。未启动时不展示这些信息，只提示先点顶部「启动」。
- 「测试」展示三个 curl 示例：GET `/v1/models`、POST `/v1/chat/completions`、POST `/v1/responses`。复制按钮只在服务运行时可用；复制成功或失败都有反馈。使用第一把客户端密钥，默认遮挡，可切换显示；复制包含真实客户端密钥，绝不包含上游凭据。展示按 shell 语法高亮，复制的仍是纯文本命令。
- 运行时命令和接入信息使用当前绑定地址。未启动时测试命令仍用已保存地址展示，但不能复制。监听修改尚未重启时仍使用旧绑定地址。
- 运行时自动读取模型列表，默认选择首项，可手动选择，两个生成示例共用模型。列表变化后失效选择回退到首项。
- 未启动、读取失败或没有模型时使用 `<MODEL_ID>` 并提示替换；停止状态提示使用顶部启动按钮，不自动启动。
- 导航栏成功点「启动」后，提示「服务已启动」，并说明可以到首页看接入方式。人已经在首页、或这一页还在展示上游卡片时也提示。停止和重启成功不提示。启动失败只显示失败原因。
- 读取凭据失败显示错误与重试，不误报为零凭据。首页定期刷新，返回首页读取最新状态。

## 验收与范围

验证七张卡片导航、默认入口、登录与 API key 两种分支、清空后回退、分段默认停在「接入」、未启动时接入不展示信息且测试不能复制、启动后地址与密钥可复制、三个复制按钮的真实内容、密钥遮挡、模型联动、停止与错误占位、监听未重启地址，以及命令高亮不改变复制内容。仅请求模型列表，不自动执行生成请求，不保证所有模型同时支持两种生成协议。高亮使用 sugar-high。无凭据迁移。
